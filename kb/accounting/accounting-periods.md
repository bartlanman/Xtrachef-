## What it is
Accounting Periods define each location's fiscal calendar in xtraCHEF. They're **required per location** before the **Budgets, COGS and Operating Summary** reports work.

## When you'd use it
- During setup, before using COGS or budgets.
- At the start of each new fiscal year.

## How to do it
1. **gear icon > Account Setup**.
2. Under **Budgets** on the right, click **Accounting Period**.
3. Click **+ Add New Period** (top right).
4. Fill in:
   - **Location**
   - **Year**: choose the previous year to close out the current fiscal year, or the current year to start a new period.
   - **Start Date**: the day the period starts and the weekday it resets on.
   - **Period Type**: one of the options below.
5. Click **+ Add**.

**Period types**
- **52 Periods (5-4-4)**, **(4-5-4)** or **(4-4-5)**: four 13-week quarters in the given pattern of weeks per month.
- **13 4-week Periods**: thirteen 28-day periods.
- **12 Calendar Months**: the suggested default if you don't already have a system.

## Settings, options & permissions
- Set from Account Setup. In practice this is Tenant Admin.

## Rules, limits & gotchas
- **One period setup per location**, even if every location shares the same calendar.
- **Periods lock once created.** To edit or remove one, email support@xtrachef.com.
- Match the period type to the accountant's or QBO's calendar, or COGS won't line up with the P&L.

## Automation / efficiency angles
- For Basic City: use **12 Calendar Months** so xtraCHEF COGS lines up with the monthly QBO P&L and the monthly Great Ledger reading. Get it right the first time, because only support can change it.
- Put a January reminder on the calendar to confirm the new year's period exists for every location.

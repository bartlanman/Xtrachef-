## What it is
A permissions reference for the Inventory module (Pro). It shows which inventory actions belong to Tenant Admins, which to Restaurant Managers, and which can be granted to individual users through **User-Based Access**, typically by assigning a user to a specific area.

## When you'd use it
- Deciding who can build count lists and who can only count.
- Troubleshooting "I can't see the count" or "I can't edit the list" complaints.

## How to do it
The article has no procedure. The feature list below covers the three access columns (Tenant Admin, Restaurant Manager, User-Based Access). The yes/no cells are images on the live page, so check the live table for exact grants.
- **Area setup**: first-time area setup; add, modify or delete an area; assign the Restaurant Manager role to an area; assign users to an area; add or update notes; modify the schedule.
- **Count lists**: create; add or remove invoice items, products or prep recipes; update products and their UOM configuration; update PAR levels; delete; publish or unpublish; preview; copy.
- **Counting**: add an inventory (create an instance); start or edit counting; download counts.

## Settings, options & permissions
- **Executive** and **Invoice Capture** roles have **no Inventory access**.
- Tenant Admins have full control. Restaurant Managers handle most setup for their locations. User-based access lets a regular user count the areas they're assigned to.
- Give each user **one role only**. Multiple roles can eventually cause login and access problems.

## Rules, limits & gotchas
- An Executive can't count inventory, even though the role sees reports.
- Area assignment is what gives a Restaurant User counting rights for specific areas.

## Automation / efficiency angles
- For Basic City: assign bar staff to the "Bar / Cooler" area and kitchen staff to "Walk-in / Dry Storage". Each crew sees only its own list, which makes month-end counts faster.
- Keep count-list editing (PAR, UOM) with one or two managers so the lists stay consistent between periods.

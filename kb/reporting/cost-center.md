## What it is (2-4 sentences)
Cost centers let you tag expenses from non-revenue parts of the business (marketing, maintenance, accounting firm) that don't fit a GL or custom category. A cost center code works like a GL code for non-GL items and can drive approval rules. **Not available if a QuickBooks Online or Desktop extract is enabled.**

## When you'd use it
- Only for tenants without a QuickBooks extract. Basic City (QBO) cannot use it — use QBO classes instead.

## How to do it (numbered steps with exact menu paths, button and field names)
**Create**: **gear** icon → **Cost centers** → select your **Cost Center Chart** → **Create Cost Center** → **Cost Center Code** + **description** → **Save**.
**Update**: gear → Cost centers → select one → **Update** → edit code/description/**enable** → **Update** (takes effect immediately).
Can be used in **Approval Rules**; cost-center approval rules must include all vendors in their conditions.

## Settings, options & permissions (which roles can do it)
- Gear-menu (admin) settings.

## Rules, limits & gotchas (sync errors, mapping rules, what syncs vs what doesn't, timing)
- Disabled whenever a QB extract is on.

## Automation / efficiency angles
- For QBO users, achieve the same split with QBO Class tracking (see class-or-location-tracking note).
